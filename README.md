### Giulio Franzese

Assistant Professor, Data Science Department, [EURECOM](https://www.eurecom.fr/) —
generative modelling and information theory.

Diffusion-based estimators of information-theoretic quantities:
[MINDE](https://arxiv.org/abs/2310.09031) (ICLR 2024, set the state of the art for
neural mutual-information estimation) ·
[SΩI](https://arxiv.org/abs/2402.05667) (ICML 2024 oral, first scalable O-information
estimator) · [TENDE](https://arxiv.org/abs/2510.14096) (AISTATS 2026) ·
[INFO-SEDD](https://arxiv.org/abs/2502.19183) (ICLR 2026) ·
[ALICE](https://arxiv.org/abs/2609.34962) (2026, first zero-shot MI estimator: one pretrained
model, in-context, no per-dataset training).
📝 Technical explainers, one per method, with the shared derivation: [mutual information](https://franzese.eurecom.io/notes/mutual-information.html) · [O-information](https://franzese.eurecom.io/notes/o-information.html) · [transfer entropy](https://franzese.eurecom.io/notes/transfer-entropy.html) · [integrated information](https://franzese.eurecom.io/notes/integrated-information.html) · [discrete data](https://franzese.eurecom.io/notes/discrete-data.html) · [unpaired matching](https://franzese.eurecom.io/notes/ddmec.html) · [trajectories](https://franzese.eurecom.io/notes/functional-kl.html) · [in-context estimation](https://franzese.eurecom.io/notes/alice.html)

Current focus: trajectory inference — relative-entropy estimation in function
space, [ICML 2026](https://arxiv.org/abs/2604.20775) — and, separately, ongoing
work on foundation models for trajectory inference.
